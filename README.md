# 🎓 Student Command Center

A Python-based application designed to help students manage and organize different aspects of their academic and daily life from one place.

The Student Command Center combines multiple useful tools into a single application, including study tracking, expense tracking, assignment management, weather information, GitHub repository analysis, web information, and statistics.

---

## ✨ Features

### 📚 Study Tracker

The Study Tracker allows users to record and manage their study sessions.

Users can store information such as:

- Subject
- Topic
- Study time

The data is stored using an SQLite database, making it possible to keep track of study activities over time.

---

### 💰 Expense Tracker

The Expense Tracker helps users record and manage their expenses.

Users can store information such as:

- Date
- Category
- Description
- Amount

This allows users to keep track of their spending and better understand their expenses.

---

### 📝 Assignment Tracker

The Assignment Tracker helps students manage their assignments and deadlines.

Users can store information such as:

- Subject
- Assignment name
- Due date
- Completion status

This makes it easier to organize academic tasks and keep track of pending assignments.

---

### 🌤️ Weather Information

The Weather feature provides weather information for a selected location.

The application uses APIs to retrieve location and weather data and display relevant weather information to the user.

---

### 🔍 GitHub Repository Analyzer

The GitHub Repository Analyzer allows users to analyze information about a GitHub repository.

The application uses the GitHub API to retrieve repository information and display useful details.

---

### 🌐 Web Information

The Web Information feature allows users to search for information from the web.

The application retrieves and processes online information using web requests and HTML parsing.

---

### 📊 Statistics

The Statistics feature provides an overview of the information stored in the application.

It helps users view and understand their tracked data more easily.

---
